# The kdb Application Suite

These are the rather primitive applications I created along with the `kdb` package.  This is a personal hobby project that I was never going to release, but after putting up the updates to *System Manager* and since it had `kdb` integration, I thought that, why not?  I'll put this hobby project up to.  If it benefits anyone then great, if not, it'll just rot here on GitHub.

### DBManager

The *DBManager* will display all of available databases within the designated database directory.  You can choose a database, and then perform many filters on the data itself.

For example: `DTOS(ADDED)>'20260501'`  On the logs database will show all entries after May 1st, 2026.

To search for a specific message, you can do this: `Message='*corpnet.sl'`, which when used with the *System Manager* will show you when this system list was opened.

### DBLog Viewer

I personally have this program opened on my second monitor at all times, so I can easily just glance to see the progress of any given task that I am working on.  It also provides a means to only see log entries for a specific **Application Name**, which is saved to the database using the provided unit `kdblog`.

### DBLog Journal Viewer *AKA* CannaLog

This special program, can be preprogramed, as remember, this is a hobby project, not meant for anyone but really me to use, so yes, no configuration, recompile to add new filters.  It works for my workflow, as I don't usually add them very often, and it's the quickest and easiest solution for a personal hobby project.  You can select one of the compiled-in filters, and attach a journal entry to any of the log entries displayed in the grid.  The filter chooser will change what records from the log database are displayed here.  Double-click on a line to open the journal editor where you can jot down some notes about this log entry.  A report can also be generated by pressing the **Report** button, which will generate an *HTML file* containing the log's timestamp, along with the note from that log entry.  This can then be searched itself using regular file searching means.

### Note Editor

This should be opened first to initialize the actual notes database, which is needed to use the journal features of the *DBLog Journal Viewer*.  This program isn't really recommended for any other use than database initialization, as it was built only to create and test that database with limited additional uses.

### ProjMan

A very primitive desktop kanban board with the absolute most minimum required for the kanban to work.  A filter feature similar to the *Game Manager* will be added at some point.  This also uses the notes database to store it's own notes.

### VFS Browser

Basic virtual file system, it can store and run links to programs, so it can work as a sort of program launcher.

### VFS Explorer

A demonstration/test program for the VFSTreeView LCL component included in the `kdblaz.lpk` package.
